# App

Install and run:

```bash
npm.cmd install; npm.cmd run dev
```

Open:

```text
http://127.0.0.1:5173/product/yogabar-protein-bar-chocolate-chunk-and-nuts-pack-1-60g
```

The app reads `public/products.json`, which is generated by `python ../ingest/ingest.py` from the SQLite-backed ingestion flow.
